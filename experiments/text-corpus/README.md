# text-corpus — labeled AI-text benchmark seed

Small labeled corpus for `experiments/eval_text_detect.py`. `manifest.json`
lists every sample with `label` (ai|human), `generator`, and `language`.

## Sources and licenses

- `ai/devin_doc*.md` — project docs written by the Devin agent in this
  repository (generator: `devin`). Repo license applies.
- `ai/ai_claude_*.txt|.md` — text generated by Claude during this session
  (generator: `claude`), including formal prose, agent-style markdown,
  humanized/informal, and boilerplate-style hard cases.
- `human/wiki_*.txt` — Wikipedia article extracts (human-written),
  CC BY-SA 4.0. Source: ko.wikipedia.org / en.wikipedia.org REST API.
- `human/mit_license.txt` — OSI MIT license text (boilerplate hard-negative).

## Coverage gaps (must be filled before accuracy claims)

- No real Codex/Gemini/Grok/Kimi outputs yet — contribute samples with
  `generator` labels to extend the manifest.
- Human Korean is formal encyclopedic prose only; informal human Korean
  (chat, blogs) is missing.
- n=22 is a smoke-size corpus, not a benchmark — metrics in
  `TEXT_DETECTION_EVAL.md` are directional, not publishable accuracy.
